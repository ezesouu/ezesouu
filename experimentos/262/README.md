# Error del factor $$V\Delta P$$ inducido por el $$\text{H}_2$$ en la entalpía del $$\text{Li}$$, $$\text{Na}$$ y $$\text{K}$$

## Qué es
La entalpía equivale a:
```math
H=U+PV
```
Aplicamos variabilidad:
```math
\Delta H=\Delta U+\Delta(PV)
```
Y sabiendo que:
- $$\Delta U=Q-W,$$
- $$Q=mc_e\Delta T,$$
- $$W=P\Delta V$$
- $$\Delta(PV)=P\Delta V+V\Delta P$$

Podemos deducir finalmente que:
```math
\Delta H=mc_e\Delta T-P\Delta V+P\Delta V+V\Delta P
```
Y finalmente:
```math
\Delta H_A=mc_e\Delta T+V\Delta P
```
Pero si consideramos que la reacción ocurre en un ambiente abierto, entonces $$\Delta P\approx0$$, y por ende,
```math
\Delta H_B=mc_e\Delta T
```

Ya que
```math
\Delta H=mc_e\Delta T+V\cdot0
```
## Objetivo
A partir de las reacciones
```math
2\text{X}+2\text{H}_2\text{O}\to2\text{XOH}+\text{H}_2,
```
calcular experimentalmente
```math
\epsilon=\frac{\Delta H_A}{\Delta H_B}-\Delta H_B
```
para cada alcalino mencionado, y graficar $$\Delta H_X(m)=mc_{e_X}\Delta T_X$$ en el mismo eje de coordenadas.
> [!NOTE]
> $$\Delta P$$ es la diferencia de presión de gas (aire + $$\text{H}_2$$) justo antes del inicio de la reacción y en el momento del equilibrio térmico.
> 
> Asimismo, $$\Delta T$$ es la diferencia de temperatura del solvente (agua destilada, $$\text{H}_2\text{O}$$) justo antes del inicio de la reacción y en el momento del equilibrio térmico.
